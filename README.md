# Student Management System

A desktop-based student management application developed using **Java, JavaFX, and Maven** as part of a university team project.

## Overview
The Student Management System is designed to organize and manage student information through a graphical user interface.

The application provides features for student registration, viewing student records, managing grades, and accessing student-related reports.

## Key Features
- **Login Interface:** Provides an entry point to the application.
- **Dashboard:** Allows navigation between different sections.
- **Student Registration:** Add and manage student information.
- **Student Records:** View student details.
- **Grade Management:** Add and manage student grades.
- **Reports:** Access student-related reports.

## Technologies Used
- Java
- JavaFX
- Maven
- JavaFX Scene Builder
- Object-Oriented Programming (OOP)
